# Security Policy

Reflexes is an open safety harness for AI agents (inference-time policy
checks), so we take security reports seriously. Thank you for helping keep
Reflexes and its users safe.

## Supported versions

Security fixes are provided for the current `0.1.x` release line.

| Version | Supported          |
|---------|--------------------|
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a vulnerability

**Please do not open a public GitHub issue for security matters.**
Public issues disclose the problem before a fix is available and put
other users at risk.

Instead, report privately by email to **info@zentropi.ai**. If you
prefer, use GitHub's private
["Report a vulnerability"](https://github.com/zentropi-ai/reflexes/security/advisories/new)
flow instead.

Please include as much of the following as you can:

- A description of the vulnerability and its impact.
- The affected version(s) or commit.
- Step-by-step instructions to reproduce it, including any
  configuration (`reflexes.yaml`, policy files) needed — **redact API
  keys and secrets**.
- A proof of concept, if you have one.
- Any suggested remediation.

## What to expect

- We will acknowledge your report within a few business days.
- We will keep you updated as we investigate and work on a fix.
- We aim for coordinated disclosure: we will agree on a disclosure
  timeline with you, credit you if you wish, and publish an advisory
  once a fix is available.

Please give us a reasonable opportunity to address the issue before any
public disclosure.
